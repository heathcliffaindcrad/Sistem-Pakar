Repositori ini berisi implementasi sistem pakar berbasis metode Forward Chaining dan Backward Chaining menggunakan Python dalam bentuk Jupyter Notebook. Proyek ini bertujuan untuk menunjukkan cara kerja kedua metode inferensi dalam pengambilan keputusan otomatis. Tersedia juga contoh kasus penerapan dalam bidang medis, yang dapat dijadikan acuan untuk pengembangan sistem pakar di berbagai domain.
